The crude prevalence ratios (PRs) in Chapter 7 mix the association of income with the associations of everything that travels with income. Age is the clearest example: adults 65 and older are less likely than middle-aged adults to have a high household income (many are retired) and far more likely to have diabetes. A multivariable model estimates the association of income with diabetes among adults of the same age group, sex, and race and ethnicity.

8.1 Helpers

The three helper functions are the same as in Chapter 7.

Show / hide code 
# Fit one model per completed dataset; keep the estimates, their covariance matrix, and the
# residual degrees of freedom. Each design is built, used, and discarded in turn.
fit_each <- function(imputed, formula) {
  purrr::map(seq_len(imputed$m), \(i) {
    design <- mice::complete(imputed, i) |>
      dplyr::mutate(diabetes_yes = as.integer(diabetes == "Yes")) |>
      srvyr::as_survey_design(
        ids = psu_id,
        strata = strata,
        weights = weight,
        check_strata = FALSE
      )
    fit <- survey::svyglm(
      formula,
      design = design,
      family = stats::quasipoisson()
    )
    list(
      coef = stats::coef(fit),
      vcov = stats::vcov(fit),
      df = stats::df.residual(fit)
    )
  })
}

pool_fits <- function(fits) {
  estimates <- purrr::map(fits, \(fit) {
    tibble::tibble(
      term = names(fit$coef),
      estimate = fit$coef,
      std.error = sqrt(diag(fit$vcov)),
      df.residual = fit$df
    )
  })
  mice::pool.table(purrr::list_rbind(estimates), exponentiate = TRUE)
}

format_pr <- function(pooled) {
  pooled |>
    tibble::as_tibble() |>
    dplyr::filter(term != "(Intercept)") |>
    dplyr::transmute(
      term,
      `PR (95% CI)` = sprintf(
        "%.2f (%.2f to %.2f)",
        estimate,
        conf.low,
        conf.high
      ),
      p = format.pval(p.value, digits = 2, eps = 0.001)
    )
}

Each adjusted PR compares two groups that are alike on the other variables in the model. For example, the PR for income$100,000 or more compares adults in the highest income group with adults earning less than $25,000 of the same age group, sex, and race and ethnicity.

8.3 Does income matter overall?

Income has four groups, so it has three PRs, each with its own p-value. To ask whether income is associated with diabetes at all, we test the three coefficients together (null hypothesis: all three are zero on the log scale). mitml::testConstraints() runs this multivariate Wald test across imputations (the “D1” statistic, pooled with Rubin’s rules) from each dataset’s estimates and covariance matrix.

Show / hide code 
income_terms <- grep("^income", names(adjusted_fits[[1]]$coef), value = TRUE)
income_test <- mitml::testConstraints(
  qhat = do.call(cbind, purrr::map(adjusted_fits, "coef")),
  uhat = simplify2array(purrr::map(adjusted_fits, \(fit) fit$vcov)),
  constraints = paste0("`", income_terms, "`"), # backticks: the names contain spaces
  method = "D1",
  df.com = adjusted_fits[[1]]$df # complete-data survey residual degrees of freedom
)

8.4 Sensitivity analysis: complete cases

How much did imputation change the results? The same model fit to complete cases drops everyone with a missing value. survey::svyglm() keeps the full design for the variance and gives the dropped respondents no weight in the estimates.

Show / hide code 
complete_case <- survey::svyglm(
  diabetes_yes ~ income + age_group + sex + race_eth,
  design = srvyr::as_survey_design(
    brfss_clean,
    ids = psu_id,
    strata = strata,
    weights = weight,
    check_strata = FALSE
  ),
  family = stats::quasipoisson()
)
complete_case_pr <- broom::tidy(
  complete_case,
  conf.int = TRUE,
  exponentiate = TRUE
)
complete_case_n <- stats::nobs(complete_case)
rm(complete_case) # Cache the small results, not the full model object.

Where do the missing data matter? The fraction of missing information (fmi) estimates information lost for each coefficient because of missing data. Income has the most missing values, but coefficients for fully observed variables can also be affected because they are estimated alongside income. Inspect the values rather than inferring them from each variable’s missingness percentage.

ImportantWhen the two analyses disagree

If complete-case and imputed results differ substantially, report both and explain why, rather than choosing the one you like better. Under MAR, well-specified imputation models can reduce bias; MAR alone does not establish that the imputed results are better. Agreement also does not validate either approach. Assess the imputation model and consider sensitivity analyses for MNAR.

8.5 Reporting the results

Show / hide code 
top_income <- dplyr::filter(adjusted, term == "income$100,000 or more")
top_income_cc <- dplyr::filter(
  complete_case_pr,
  term == "income$100,000 or more"
)

A results paragraph might read:

We analyzed 457,670 adults in the 2024 Behavioral Risk Factor Surveillance System, representing 263.8 million adults in the participating jurisdictions (49 states, DC, Guam, Puerto Rico, and the US Virgin Islands). The regression analyses accounted for survey weights, strata, and primary sampling units. Household income was missing for 19.1% of respondents, and missingness varied with age and general health. We multiply imputed missing values (5 imputations by chained equations with the mice package, version 3.19.0, predictive mean matching, with the survey weight as a predictor) and pooled estimates with Rubin’s rules. In a survey-weighted modified Poisson model adjusted for age group, sex, and race and ethnicity, adults with a household income of $100,000 or more had a prevalence of diabetes 0.47 times that of adults earning less than $25,000 (95% confidence interval [CI] 0.44 to 0.50; joint test of income p <0.001). In a complete-case analysis the prevalence ratio was 0.47 (95% CI 0.44 to 0.50).

This is an illustrative analysis of cross-sectional, self-reported data. Adjustment does not make the association causal: illness can affect income, and unmeasured factors can affect both. The diabetes measure omits undiagnosed disease and pregnancy-only diabetes. The short imputation run and omitted geographic and stratum predictors need further evaluation before substantive reporting.
