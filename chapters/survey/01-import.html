4.1 Overview

NoteThe task: answer a population question from a national survey

The chapters in this part of the book walk through one complete analysis of complex survey data in R, from downloading a raw file to reporting a multivariable model:

  1. importing a large survey file (this chapter);
  2. data engineering: stacking survey files and joining a lookup table (Chapter 5);
  3. cleaning and recoding with explicit checks (Chapter 6);
  4. survey-weighted descriptive statistics (Chapter 7);
  5. multiple imputation (MI) of missing data, with a discussion of survey-design assumptions (Chapter 8);
  6. bivariate (crude) survey-weighted regression (Chapter 9);
  7. multivariable (adjusted) survey-weighted regression, a sensitivity analysis, and reporting (Chapter 10).

The question. Is household income associated with reported diagnosed diabetes among adults in the participating BRFSS jurisdictions? Diabetes is common, costly, and unequally distributed. Income shapes access to healthy food, safe places to be active, health care, and the time and resources to manage a chronic condition. We estimate how the prevalence of diabetes differs across income groups, before and after accounting for age, sex, and race and ethnicity.

These chapters assume you have worked through Chapter 3, or are comfortable with dplyr verbs and joins, and that you know the basics of regression.

4.2 The Behavioral Risk Factor Surveillance System

The Behavioral Risk Factor Surveillance System (BRFSS) is the largest continuously running health survey in the world. Every year, the Centers for Disease Control and Prevention (CDC) and the states interview hundreds of thousands of US adults by landline and cell phone about their health conditions, health behaviors, and use of health care. In 2024, 457,670 adults in 49 states, the District of Columbia, Guam, Puerto Rico, and the US Virgin Islands completed the interview (Tennessee did not collect enough data to be included).

The target is noninstitutionalized adults aged 18 or older in these participating jurisdictions. The combined results include the territories and exclude Tennessee; they are not estimates for all 50 states and DC. See the 2024 survey overview.

BRFSS is a complex survey:

  • Strata. Each state’s sample is drawn separately within strata (for example, by region and by landline or cell phone).
  • Primary sampling units (PSUs). Within a stratum, phone numbers are sampled. In BRFSS each respondent is their own PSU.
  • Weights. People are sampled with different probabilities and respond at different rates. CDC’s final weight (_LLCPWT) adjusts for selection and nonresponse and makes the weighted sample match each state’s adult population by age, sex, race and ethnicity, education, and other characteristics (“raking”).

Every estimate in these chapters uses all three. Chapter 7 shows what happens when they are ignored.

4.3 Download the data (run once)

CDC distributes the data as a zipped SAS transport file (.XPT), a format that stores a SAS dataset in a portable way. Allow several gigabytes for the downloads, extracted files, and analysis outputs; file sizes can change between releases.

Run the chunk below once, by hand, from the R console in the book’s root folder (it is not run when the book is rendered). It saves data/brfss/raw/LLCP2024.XPT. Raw data, processed data and caches are excluded from Git.

Show / hide code 
dir.create("data/brfss/raw", showWarnings = FALSE, recursive = TRUE)
zip_file <- "data/brfss/raw/LLCP2024XPT.zip"
options(timeout = 600) # allow 10 minutes on a slow connection
utils::download.file(
  "https://www.cdc.gov/brfss/annual_data/2024/files/LLCP2024XPT.zip",
  destfile = zip_file,
  mode = "wb"
)
# The zip file names its contents "LLCP2024.XPT " (with a trailing space), so rename
# the file.
extracted <- utils::unzip(zip_file, exdir = "data/brfss/raw")
file.rename(extracted, "data/brfss/raw/LLCP2024.XPT")
file.remove(zip_file)

You can also download the zip file from the CDC BRFSS 2024 page (“2024 BRFSS Data (SAS Transport Format)”), unzip it, and save the file as data/brfss/raw/LLCP2024.XPT. The same page has the codebook, which lists every variable, its question, and its codes, and the questionnaire version files used in Chapter 5.

4.4 Read only the columns we need

The file has 301 columns. We need 14, so we read only those with col_select. This keeps memory use low and makes reading fast. It does not change the survey design: every one of the 457,670 respondents is kept, with their weight, stratum, and PSU.

Names that start with an underscore are variables CDC calculated. In R they must be wrapped in backticks, as in `_LLCPWT`, not in quotation marks.

4.6 How the code in this part is written

  • Functions from add-on packages use their package name, as in dplyr::mutate(); base R functions such as readRDS() are used directly.
  • |> is R’s pipe: x |> f() means f(x).
  • Lines that start with # Check: stop the code with an error if an assumption about the data fails. A silent check means the data are as expected.
  • tidylog:: versions of dplyr verbs print what each step did (rows dropped, variables created, share missing).
